# 09 · Glosario

Los términos del dominio se escriben **siempre igual**, en documentación, código e interfaz. Esta
lista manda sobre cualquier otra forma que aparezca en textos antiguos del repositorio.

| Término | Identificador | Qué es |
|---|---|---|
| Acontecimiento | `acontecimiento` | Suceso anunciado con antelación que afecta a una región (sequía, peste, buen año) |
| Aperos | `aperos` | Nivel de herramienta de hierro de una comarca; sube toda su producción |
| Bastimento | `bastimento` | Provisiones que consume una recua por jornada |
| Cabecera | `cabecera` | Localidad principal de una comarca |
| Camino | `camino` | Arista del grafo entre dos comarcas, con su calidad y su coste en jornadas |
| Cañada | `canyada` | Camino trashumante histórico, con reglas propias para los rebaños |
| Carga | `carga` | Unidad de volumen de recursos (≈ lo que lleva una acémila) |
| Carta puebla | `carta_puebla` | Fuero menor que fomenta la repoblación |
| Casa | `casa` | La facción del jugador: su oficio (Mesta, ferrones, canteros…) |
| Comarca | `comarca` | Unidad de territorio del juego |
| Concejo | `concejo` | Gobierno local de una comarca neutral; recibe regalos e influencia |
| Crónica | `cronica` | Parte del turno que recibe cada jugador |
| Cuadrilla | `cuadrilla` | Equipo de obra de una comarca; una obra ocupa una |
| Escasez | `escasez` | Estado en que el pan disponible no cubre el consumo |
| Feria | `feria` | Mercado grande en fechas fijas del calendario |
| Fuero | `fuero` | Estatuto que da autonomía: menos impuestos, más lealtad |
| Hito | `hito` | Logro que registra el progreso y otorga prestigio |
| Influencia | `influencia` | Apoyo acumulado en una comarca neutral (0–100) |
| Jornada | `jornada` | Unidad de distancia y tiempo de viaje |
| Lealtad | `lealtad` | Apego de una comarca a su señor (0–100) |
| Maravedí | `maravedi` | Moneda del juego |
| Mayordomo | `mayordomo` | Conjunto de reglas permanentes que actúan en ausencia del jugador |
| Menor (mercader menor) | `mercader_menor` | Agente sintético que da liquidez a una plaza; sus compras y ventas desaparecen con el comercio entre jugadores |
| Merma | `merma` | Pérdida de pan almacenado por turno |
| Obra mayor | `obra_mayor` | Proyecto de decenas de turnos con efecto permanente |
| Pan | `pan` | Recurso alimentario |
| Plaza | `plaza` | Mercado abierto este turno: un mercado local o una feria en sus fechas |
| Portazgo | `portazgo` | Peaje que cobra el dueño de un camino |
| Potencial | `potencial` | Aptitud fija de una comarca para un recurso (0–5) |
| Prestigio | `prestigio` | Puntuación pública del jugador |
| Puebla | `puebla` | Asentamiento nuevo fundado con gente llevada por una recua |
| Quincena | `quincena` | Duración de un turno en el calendario del juego |
| Rebaño | `rebanyo` | Unidad móvil de ganado trashumante |
| Recua | `recua` | Unidad móvil de transporte y expedición |
| Solar | `solar` | Hueco de edificación en una comarca |
| Tratar | `tratar` | Cometido de una recua quieta en una plaza: comprar y vender allí con precio límite |
| Tradición | `tradicion` | Rama de desarrollo que elige una casa al alcanzar un hito |
| Vecino | `vecino` | Unidad de población (una familia) |

Notas de escritura:

- En identificadores y nombres de archivo no se usan tildes ni eñes: `canyada`, `rebanyo`, `maravedi`.
- Plural de recua: recuas. De rebaño: rebaños. De maravedí: maravedís.
- «Comarca propia» y «comarca neutral», nunca «territorio» a secas.
- El jugador es «el señor de la casa»; nunca «el usuario» en textos de juego.
